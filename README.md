# idea-kubernetes-files

为 IntelliJ IDEA 原生 Kubernetes 插件增加容器文件浏览功能。

## 功能范围

- 在 Pod 详情中新增 **Files** 入口。
- 支持按目录树浏览容器内文件。
- 支持查看文本文件内容（只读）。
- 支持基础文件操作：刷新、下载到本地。

## 交互说明

1. 在 Kubernetes 视图中选择目标 Pod/Container。
2. 打开 **Files** 视图后自动加载根目录。
3. 点击目录可展开子目录，点击文件可在右侧预览。
4. 通过工具栏执行刷新与下载操作。

## 约束

- 默认只读，不提供删除/修改容器文件能力。
- 文件读取需遵循已有 Kubernetes 连接与权限模型。
- 大文件按大小限制读取，避免阻塞 IDE。
